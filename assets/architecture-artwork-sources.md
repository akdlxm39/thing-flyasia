# System architecture artwork

The diagram was reconstructed with native SVG lines, rounded rectangles, and
text. Hardware photographs are retained unchanged from the project-supplied
THING architecture diagram. The reconstruction replaces the traced software
artwork with the following sources:

- React, JavaScript, Vite, Tailwind CSS, Docker, Ubuntu, C++, Python, OpenCV,
  Raspberry Pi, Django, NGINX, SQLite, and AWS:
  [Devicon](https://github.com/devicons/devicon), MIT license.
- ROS nine-dot mark:
  [Open Robotics artwork](https://github.com/openrobotics/artwork/blob/master/ros_logo.svg),
  CC BY-NC 4.0. The nine-dot portion was cropped from the original artwork;
  the ROS 2 Humble caption was added separately.
- MediaPipe and NVIDIA mark:
  [Simple Icons](https://github.com/simple-icons/simple-icons), CC0 distribution.
  cuDNN, TensorRT, CUDA, and Jetson are written as separate product labels.
- Gunicorn: [official SVG](https://gunicorn.org/assets/gunicorn.svg).
- Let's Encrypt:
  [official SVG](https://letsencrypt.org/images/letsencrypt-logo-horizontal.svg).
- Cyclone DDS:
  [official artwork](https://cyclonedds.io/images/cyclonedds.png), embedded
  losslessly at its original 1920 x 1780 pixel resolution.
